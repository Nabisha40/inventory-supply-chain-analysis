# 📦 Inventory-And-Supply-Chain-Analysis

Data Analytics project showcasing Inventory and Supply Chain Analysis using Excel and Power BI

## 📌 Project Overview

**Inventory And Supply Chain Analysis** is an end-to-end data analytics project focused on analyzing inventory performance, warehouse utilization, transportation costs, sales trends, lead times, backorders, and regional inventory distribution.

This project uses **Microsoft Excel and Power BI** to transform supply chain data into meaningful business insights. The workflow includes data preparation, data cleaning, analysis, KPI development, dashboard creation, and business insight generation.

The main objective is to provide a centralized view of supply chain performance and help businesses make data-driven decisions related to inventory management, warehouse utilization, logistics, and order fulfillment.

## 🎯 Project Objectives

- Analyze inventory performance and distribution.
- Monitor warehouse utilization.
- Evaluate Days Sales of Inventory.
- Analyze inventory turnover ratio.
- Analyze transportation costs across regions and categories.
- Identify yearly sales and units sold trends.
- Compare average lead time across product categories.
- Analyze backorders by order status.
- Evaluate inventory levels across regions and categories.
- Build an interactive Power BI dashboard.
- Generate actionable business insights and recommendations.

## 📊 1. Excel Data Preparation

The initial dataset was prepared and reviewed using **Microsoft Excel** before being analyzed in Power BI.

### Data Preparation Activities

- Reviewed dataset structure and fields.
- Checked data consistency.
- Reviewed numerical and categorical values.
- Identified potential data quality issues.
- Organized the dataset for analysis.
- Prepared the data for Power BI integration.

Excel was used as the supporting data preparation and analysis tool before developing the interactive Power BI dashboard.

## 📐 2. Power BI Data Modeling & KPI Development

The prepared dataset was imported into **Power BI** for further analysis and visualization.

DAX measures were developed to calculate important supply chain KPIs and performance indicators.

### Key KPIs

| **KPI** | **Value** |
| ------- | --------: |
| **Warehouse Utilization** | 34.08 |
| **Days Sales of Inventory** | 15.56 |
| **Inventory Turnover Ratio** | 23.47 |

These KPIs provide a high-level overview of inventory and warehouse performance.

## 🏭 3. Warehouse Utilization Analysis

The dashboard analyzes warehouse utilization to provide visibility into the usage of available warehouse capacity.

This metric can help businesses evaluate warehouse efficiency and support better capacity planning.

Average lead time is analyzed across different product categories to understand supply chain efficiency.
